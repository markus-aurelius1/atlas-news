# Bundled editorial fonts

Geist Sans (400–700) and Newsreader (optical size 6–72, weight 400–600, upright and italic), Latin variable WOFF2 subsets. Downloaded 2026-10-04 from the official Google Fonts service. No runtime font requests or npm font dependencies were added.

- Geist: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFU.woff2
- Newsreader: https://fonts.gstatic.com/s/newsreader/v26/cY9AfjOCX1hbuyalUrK4397yjA.woff2
- Newsreader Italic (same axes, for quotations and emphasis in the News reader), downloaded 2026-10-06: https://fonts.gstatic.com/s/newsreader/v26/cY9CfjOCX1hbuyalUrK439vCjohC.woff2
- Licences: upstream `google/fonts` `ofl/geist/OFL.txt` and `ofl/newsreader/OFL.txt`, bundled beside these assets.

The existing Manrope/Fraunces font assets remain. Atlas label measurement and painting explicitly retain Manrope; the UI font change must never change cartographic metrics.
