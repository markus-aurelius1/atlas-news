# One consolidated independent editorial review

Give the owner **only `blind-review-v2/`**, and open `index.html` in a normal browser. This is the final package: 50 articles, ten natural comparison opportunities, captured metadata only, no visible predictions or suggested labels. It works offline and exports `tars-independent-review.json`. Article bodies are neither fetched nor included. Name, publication time, publisher/section, description availability, URL and provenance are shown; missing metadata is never filled.

Sample SHA-256: `853a8bc657b4a78faeda25a95219dd95248ae7cb0d5f2a6f2651deaa1118b547`. `sample.json` and `hashes.json` bind the package. Actual metadata cutoff: `2026-10-07T13:40:55.600Z`; this historical review does not certify current freshness or temporal behavior. Deterministic seed: `tars-rc-blind-2026-10-09/2`.

Choose value, primary subject and metadata sufficiency independently, with a short reason. On Comparisons, judge development, analytical relation and representative quality from the supplied evidence. Use Uncertain when evidence cannot establish equivalence or a valuable separate angle. All substantive choices start blank. Drafts save locally when available; export before moving the file or clearing browser data. Export marks incomplete work partial and leaves unanswered judgments blank. Resume import rejects a different sample or invalid labels and asks before replacing existing drafts. No human-reviewed file has been imported in this release task.

This is an enriched independent **human review package**, not a sealed future holdout and not a statistically representative production sample. The underlying 1,000-item historical corpus was already machine-evaluated. The final sampler first chooses cross-publisher comparison opportunities from natural headline overlap, includes mandatory-parent decision strata to ensure decision coverage, then balances publisher, section-based subject proxies, freshness and article-type proxies with deterministic hash tie-breaks. Parent predictions are sampling proxies, never human truth. Candidate predictions were computed only after this package's bytes/hashes were frozen and remain outside the reviewer directory. Neither sampling proxies nor source categories establish actual article subjects.

All 75 prior owner/calibration article identities and their URLs are excluded; known exemplar IDs/URLs are excluded too (133 identity exclusions including exemplars). All final records are explicitly unreviewed with no previous annotations. Reverse-order sampling reproduces the sample. No sealed A3/future holdout was inspected. `blind-sampling-manifest-v2.json` records exclusions and selection provenance but contains diagnostic sampling information: **do not give it or machine diagnostics to the reviewer**.
